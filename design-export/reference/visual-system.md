# Nerix Visual System

## Style

- Background: near-black `#000000` / `#050505`.
- Surfaces: `#0A0A0A`, `#0D0D0D`, transparent black overlays.
- Borders: white at 5-12% opacity.
- Text: white primary, gray secondary.
- Radius: mostly `16px` for panels, full radius for primary pills.
- Navigation: left sidebar only inside the app.
- Landing/about: space background, stars, planet/ring parallax.
- Chat: quiet black background without heavy image noise.

Use a clean sans-serif close to Inter/SF Pro:

```text

Page title: 28-36
Section title: 22-30
Body: 14-18
Caption: 12-13
```

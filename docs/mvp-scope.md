- landing and about pages;
- web app shell;
- one main chat;
- agents page;
- history page;
- memory page;
- balance page;
- settings page;
- RU/KZ/EN language support;

- mock AI Gateway;
- mock wallet/ledger.

- streaming chat;
- usage tracking;
- agent routing;
- basic admin panel.

## MVP 3

- payments;
- image generation;
- file upload and document analysis;
- Flutter app;
- business agent builder.
